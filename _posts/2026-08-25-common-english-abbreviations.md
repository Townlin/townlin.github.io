最近整理了一份常见英语缩写清单。原材料列了 32 条，其中 `RSVP` 和 `R.S.V.P.` 只是两种写法，所以合并后共有 31 组。与其逐条背诵，不如按使用场景来记：解释与举例、学术引用、工作沟通、地址与机构，以及时间与纪年。

先记住一个总原则：缩写的**写法**和**读法**不是一回事。有些缩写通常逐字母读，如 `ETA`；有些在朗读时更自然地还原成完整短语，如把 `e.g.` 读作 *for example*；另一些则已经像普通单词一样读，如 `ibid.`。具体写法还会随英式、美式及不同出版规范而变化，全文保持一致最重要。

## 最容易混淆的四个

| 缩写 | 原词 | 核心意思 | 一句话判断 |
| --- | --- | --- | --- |
| `e.g.` | *exempli gratia* | 例如 | 后面给出若干例子，不代表列举完整 |
| `i.e.` | *id est* | 即、换句话说 | 后面是在重新定义或说得更精确 |
| `viz.` | *videlicet* | 即、具体来说 | 比 `i.e.` 更正式，常引出完整清单 |
| `etc.` | *et cetera* | 等等 | 表示同类项目还有更多，没有列完 |

对比下面四句，区别就很清楚了：

- Bring a warm layer, **e.g.**, a sweater or a light jacket.<br>
  带一件保暖衣物，例如毛衣或薄夹克。
- The sample contains one noble gas, **i.e.**, argon.<br>
  样品含有一种稀有气体，也就是氩。
- We measured three variables, **viz.**, temperature, pressure, and volume.<br>
  我们测量了三个变量，具体是温度、压强和体积。
- Pack notebooks, pens, chargers, **etc.**<br>
  带上笔记本、笔、充电器等等。

简单记：`e.g.` 是 **example**，`i.e.` 是 **in essence**。这不是词源解释，只是一个方便记忆的口诀。

## 学术写作与引用

| 缩写 | 含义与用法 | 朗读提示 |
| --- | --- | --- |
| `et al.` | *et alii / et aliae / et alia*，表示“以及其他人/事物”；论文中常用于省略其余作者 | 通常读作 *et al* |
| `cf.` | *confer*，“比较”；用于提示读者将当前内容与另一处比较，并不只是普通的“参见” | 可读 *compare* 或字母 C-F |
| `ibid.` | *ibidem*，“同上、同一出处”；通常只指紧邻的上一条文献 | 读作 *ibid* |
| `op. cit.` | *opere citato*，“前引书、前引文献”；属于较老的引注方式 | 通常读作 *op cit* |
| `p.` / `pp.` | 单数“页”与复数“页码范围” | 读作 *page* / *pages* |
| `PhD` | *Philosophiae Doctor*，博士学位 | 逐字母读 P-H-D |
| `MA` / `MSc` | 文学硕士 / 理学硕士 | 通常逐字母读 |
| `BA` / `BSc` | 文学学士 / 理学学士 | 通常逐字母读 |

这里最值得注意的是 `cf.`：如果只是让读者去看另一章，直接用 *see* 往往更准确；只有需要“比较两处内容”时才用 `cf.`。另外，`ibid.` 和 `op. cit.` 并非所有引用格式都接受，正式写作应以期刊、学校或所用样式手册为准。

## 邮件、邀请与工作沟通

| 缩写 | 完整形式 | 常见用途 |
| --- | --- | --- |
| `Attn:` | *Attention* | 信件或文件上标明收件人、经办人 |
| `Re:` | “关于、事由” | 邮件主题或公函标题；不是 *reply* 的缩写 |
| `NB` | *nota bene* | 提醒读者特别注意某件事 |
| `P.S.` / `PS` | *post scriptum* | 正文写完后补充附言 |
| `RSVP` / `R.S.V.P.` | *Répondez s'il vous plaît* | 邀请函中请求对方确认是否出席 |
| `ASAP` | *As Soon As Possible* | 尽快；可逐字母读，也常读作 *ay-sap* |
| `FAQ` | *Frequently Asked Questions* | 常见问题；可逐字母读，也常读作一个词 |
| `ETA` | *Estimated Time of Arrival* | 预计到达时间 |
| `TBA` | *To Be Announced* | 信息稍后公布 |
| `TBD` | *To Be Determined* | 信息尚未确定 |
| `Q&A` | *Questions and Answers* | 问答环节 |
| `PTO` | *Please Turn Over* | 印刷材料上的“请翻页”，英式英语中更常见 |

`TBA` 和 `TBD` 的差别很实用：前者强调“稍后宣布”，后者强调“还没定下来”。例如，活动日期已经确定但尚未公开，可以写 `TBA`；场地仍在讨论，则写 `TBD`。

## 地址、机构名称与法律语境

| 缩写 | 完整形式 | 示例或说明 |
| --- | --- | --- |
| `Ave.` / `St.` / `Blvd.` / `Rd.` | *Avenue / Street / Boulevard / Road* | 常见英文地址后缀，如 `123 Main St.` |
| `Co.` / `Corp.` / `Inc.` / `Ltd.` | *Company / Corporation / Incorporated / Limited* | 公司名称中的组织形式，如 `Apple Inc.` |
| `vs.` / `v.` | *versus* | 比赛常见 `A vs. B`；案件名常见 `A v. B` |
| `No.` | *numero* | 表示“号、编号”，朗读时读 *number* |

这些缩写是否带句点，经常取决于地区与机构自己的写法。例如，公司注册名称里怎样写，就应原样保留。

## 时间与纪年

| 缩写 | 完整形式 | 含义 |
| --- | --- | --- |
| `c.` / `ca.` | *circa* | 大约、约在某年，多见于历史与艺术资料 |
| `a.m.` / `p.m.` | *ante meridiem / post meridiem* | 中午以前 / 中午以后 |
| `BC` / `AD` | *Before Christ / Anno Domini* | 公元前 / 公元纪年 |
| `BCE` / `CE` | *Before Common Era / Common Era* | 公元前 / 公元，属于更中性的写法 |

`AD` 的完整形式是 *Anno Domini*，不是常被误传的 *After Death*。`BC/AD` 与 `BCE/CE` 使用同一套年份编号，主要区别在命名方式。

## 写作时再检查五件事

1. **是在举例，还是在改述？** 举例用 `e.g.`，精确定义用 `i.e.`。
2. **是等待公布，还是尚未决定？** 等待公布用 `TBA`，尚未决定用 `TBD`。
3. **引用格式是否允许？** `ibid.`、`op. cit.` 等写法要服从指定的引注规范。
4. **有没有重复表达？** `e.g.` 后再加 `etc.`、`RSVP` 前再加 *please*、`a.m.` 后再加 *in the morning*，通常都可以精简。
5. **全文风格是否统一？** `PS` 与 `P.S.`、`vs` 与 `vs.` 都可能见到；选定一种规范后保持一致，比机械追求唯一写法更重要。

如果只想先掌握最常用的一组，可以从 `e.g.`、`i.e.`、`etc.`、`et al.`、`cf.`、`Re:`、`ASAP`、`ETA`、`TBA/TBD` 和 `a.m./p.m.` 开始。它们覆盖了日常邮件、学术阅读和一般写作中的大多数场景。
